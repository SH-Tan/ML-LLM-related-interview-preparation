# ML/LLM Interview Preparation

This repository is an interview preparation framework for machine learning,
large language model, and applied AI engineering roles.

The goal is to organize foundation knowledge, coding practice, system design,
and behavioral preparation into clear markdown files. Each file starts as an
outline so it can be expanded gradually during study.

## Knowledge and Practice Areas

- [Algorithms and LeetCode](algorithms-and-leetcode.md)
- [Machine Learning Foundations](machine-learning-foundations.md)
- [Deep Learning Foundations](deep-learning-foundations.md)
- [LLM Foundations](llm-foundations.md)
- [Machine Learning Coding](machine-learning-coding.md)
- [ML and LLM System Design](ml-llm-system-design.md)
- [Behavioral Questions](behavioral-questions.md)
- [Study Plan](study-plan.md)

## How to Use

Use this repository as a study map. Add definitions, examples, links, solved
problems, and interview notes under the relevant headings as preparation
continues.
